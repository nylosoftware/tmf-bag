
# TMF-Bag

## Features
- Three backpack levels with configurable storage capacity
- Visual backpack props that properly attach to player characters
- Integrated shop with customizable pricing
- Framework-agnostic money system (supports QB-Core, ESX, and custom frameworks)
- Prevents backpack stacking (can't put backpacks inside backpacks)
- Optional debug mode for troubleshooting

## Requirements
- ox_inventory
- ox_lib
- interact

## Configuration
Simple configuration allows you to adjust backpack storage capacity, visual props, shop pricing, and more.
